# RabbitMQ 예제 프로젝트 개요

## 프로젝트 목적
- RabbitMQ 메시지 큐와 Redis 분산 락을 활용한 재고 관리 시스템
- 동시성 제어 및 데이터 일관성 보장을 위한 다양한 락킹 전략 구현
- 비동기 메시지 처리와 시스템 분리를 통한 확장 가능한 아키텍처 학습

## 핵심 기능
1. **재고 관리 시스템**
   - 상품 생성 및 재고 조회
   - 낙관적 락 기반 재고 감소 (Prisma 버전 필드)
   - 비관적 락 기반 재고 감소 (SELECT FOR UPDATE)
   - Redis 분산 락 기반 재고 감소 (UUID 기반 락 소유권)

2. **동시성 제어**
   - 3가지 락킹 전략 비교 및 성능 테스트
   - 동시 요청 처리 테스트 엔드포인트
   - Redis 캐싱을 통한 성능 최적화

3. **메시지 큐 시스템 (계획)**
   - RabbitMQ를 통한 비동기 처리
   - 순차 처리를 위한 큐 설계
   - 백그라운드 작업 실패 처리

## 비즈니스 가치
- 전자상거래 재고 관리의 핵심 문제 해결
- 높은 동시성 환경에서의 데이터 일관성 보장
- 시스템 분리를 통한 장애 격리 및 확장성 확보
