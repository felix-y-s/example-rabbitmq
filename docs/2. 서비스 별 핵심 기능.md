 A) Inventory Service (재고 관리)

  핵심 도전과제:
  - 동시성 처리: 여러 주문이 동시에 같은 상품 구매할 때
  - 재고 예약 시스템: 결제 전까지 재고를 임시 예약
  - 분산 락: 여러 서버에서 동일 상품 접근 시 데이터 일관성
  - 재고 복구: 결제 실패 시 예약된 재고 해제

  B) Payment Service (결제 처리)

  핵심 도전과제:
  - 멱등성: 동일 결제 요청의 중복 처리 방지
  - 보상 트랜잭션: 결제 후 다른 서비스 실패 시 결제 취소
  - 타임아웃 처리: 외부 결제 API 응답 지연 대응
  - 결제 상태 추적: 비동기 결제 완료 알림 처리

  C) Order Service (주문 관리)

  핵심 도전과제:
  - 사가 패턴: 분산 트랜잭션 오케스트레이션
  - 상태 머신: 주문 상태별 전환 규칙과 검증
  - 이벤트 소싱: 주문 변경 히스토리 추적
  - 실패 시나리오: 각 단계별 실패 처리와 롤백

  D) Shipping Service (배송 관리)

  핵심 도전과제:
  - 배송지 검증: 주소 유효성 및 배송 가능 지역
  - 배송 업체 연동: 여러 택배사 API 통합
  - 배송 추적: 실시간 배송 상태 업데이트
  - 지연 처리: 재고 부족이나 결제 지연 시 배송 보류
